# Source Code Layout

Architecture placeholders only at this stage.

- `kmx/` — KMX registry, containment and resolver.
- `evidence/` — source blocks, categories and Evidence builder.
- `rules/` — Rule builder, validator and evaluator.
- `storage/` — OVH Object Storage client boundary.
- `database/` — OVH Managed PostgreSQL connection boundary.
- `sources/` — one adapter folder for each source lane.
